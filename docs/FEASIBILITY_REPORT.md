# SpinPod 首轮实机可行性报告

## 结论

SpinPod 通过 Apple 公开耳机运动 API 测量转盘转速的核心路径可行。

- 关闭“自动人耳检测”后，AirPod 离耳放在转盘上仍可连续上报运动数据；保持开启时离耳不上报。
- 静止离耳工况连续记录 71.6 秒，没有断开，滤波残余仅约 0.0027 RPM。
- 33 ⅓ 和 45 RPM 工况的读数非常稳定，窗口标准差中位数分别约 0.0416 和 0.0432 RPM。
- 两档滤波均值分别为 33.7911 和 45.5833 RPM，相对转盘档位标称值高约 1.37% 和 1.30%。转盘实际转速未知，因此这些数值不是 SpinPod 的测量误差，也不能用于判定 ±1% 准确度目标是否达成。
- 两档实测速度比为 1.34897，档位标称速度比为 1.35，相对仅差约 0.076%。这表明测量线性很好，但约 1.3% 的共同偏移可能来自转盘实际偏快、AirPods 陀螺仪比例偏差或两者共同作用，当前数据无法归因。

因此可以继续开发 iOS 原型，并把“关闭自动人耳检测”作为首次使用的强制引导。当前实验验证了 API 可用性、连续性、精密度和跨档线性，尚未验证绝对准确度；后者需要频闪盘、光学转速计或其他可信基准。

## 测试环境

| 项目 | 信息 |
|---|---|
| AirPods | AirPods 4 ANC，型号 A3057 |
| AirPods 固件 | 8B39 |
| Mac | MacBook Pro 15-inch, 2019 |
| macOS | 15.7.7（24G720） |
| 自动人耳检测 | 离耳测试时关闭；开启时离耳不上报数据 |
| 放置方式 | 耳机平放、未固定、贴近转盘中轴 |
| 数据来源 | `.tmp/spinpod-measurement-{A,B,C,D}.csv` |

本轮未固定耳机是实验方案的偏差和安全风险。靠近中轴不会影响刚体角速度理论值，但后续复测仍应固定耳机，以排除滑动并避免耳机飞出盘面。

## 分析方法

- A 对应佩戴基线，B 对应离耳静止，C 对应 33 ⅓ RPM，D 对应 45 RPM。
- 行数不包含 CSV 表头。
- 平均采样率按 `(样本数 - 1) / 记录时长` 计算。
- 转速统计使用 CSV 中 `is_stable=true` 的样本；稳定状态从约 0.76 秒开始。
- “窗口 σ”是 CSV `rpm_stddev` 列在稳定样本中的中位数和最大值。
- 超过 60 ms 的相邻时间间隔计为采样间隙；它表示短时漏样或调度延迟，不等同于耳机断连。
- C、D 的百分比仅表示读数相对转盘档位标称值的偏移，不表示相对真实转速的测量误差。

## 结果

| 工况 | 样本数 | 时长 | 平均采样率 | 最长间隙 | 稳定样本占比 | 滤波 RPM 均值 | 相对档位标称偏移 | 窗口 σ 中位数 / 最大值 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| A 佩戴基线 | 721 | 28.800 s | 25.000 Hz | 40.0 ms | 10.68% | 不适用 | 不适用 | 不适用 |
| B 离耳静止 | 1,687 | 71.583 s | 23.553 Hz | 239.8 ms | 97.21% | 0.00271 | 不适用 | 0.00445 / 0.01078 RPM |
| C 33 ⅓ RPM | 1,586 | 63.979 s | 24.774 Hz | 159.7 ms | 98.80% | 33.79113 | +1.373% | 0.04164 / 0.07299 RPM |
| D 45 RPM | 1,735 | 69.574 s | 24.923 Hz | 151.4 ms | 98.90% | 45.58332 | +1.296% | 0.04317 / 0.07552 RPM |

A 的原始换算值在约 0.016–17.141 RPM 之间随头部动作变化，采样始终保持 25 Hz，足以验证佩戴状态下的数据响应；其记录时长未达到原方案建议的 60 秒，但不影响后续离耳和转速结论。

B 在约 55–62 秒区间出现较多 0.1–0.24 秒短间隙，平均采样率相应下降，但没有长时间停流或断开。C 和 D 基本保持约 25 Hz，最长间隙均低于 0.16 秒。

## 精度边界

本轮转盘没有独立参考转速，33 ⅓ 和 45 RPM 只是档位标称值，不能当作真值。因此本轮不能计算 SpinPod 的绝对误差，也不能判定原定 ±1% 准确度要求是否通过。可计算的只有相对标称偏移和跨档线性：

```text
实测速度比 = 45.58332 / 33.79113 = 1.34897
理论速度比 = 45 / (100/3)       = 1.35000
相对差异                         ≈ -0.076%
```

这支持“传感器能稳定分辨转速，且两档之间近似线性”的结论，但不构成绝对准确度证明。下一轮应同步记录独立参考值；只有确认真实转速后，才能评估误差并决定是否需要陀螺仪比例校准系数。

## 下一步

1. 固定 AirPod，用独立转速计同时测量 33 ⅓ 和 45 RPM，各重复至少三次。
2. 改变 AirPod 朝向与放置半径，验证向量模长算法的朝向/半径不变性。
3. 记录长达 10 分钟的数据，确认关闭自动人耳检测后的持续性和采样间隙分布。
4. 在 iOS 原型首次运行时加入“关闭自动人耳检测”的阻断式引导；公开 API 无法代替用户修改该系统设置。
5. 独立参考确认后，再决定是否加入校准系数，避免把转盘真实偏速错误归因于 AirPods。
