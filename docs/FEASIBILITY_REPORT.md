# SpinPod 实机可行性报告

## 结论

SpinPod 通过 Apple 公开耳机运动 API 测量转盘转速的核心路径可行。

- 关闭“自动人耳检测”后，AirPod 离耳放在转盘上仍可连续上报运动数据；保持开启时离耳不上报。
- 静止离耳工况连续记录 71.6 秒，没有断开，滤波残余仅约 0.0027 RPM。
- 当前以 AirPods 读数作为阶段性结果：33 ⅓ 档 C 的滤波均值为 33.7911 RPM；45 档采用 10 分钟测试 F 的滤波均值 45.4930 RPM。
- 改变朝向与放置半径后，D、E1、E2 三组 45 RPM 滤波均值位于 45.4876–45.5833 RPM，所有组的单次记录标准差均不超过 0.0181 RPM。
- F 连续记录 601.5 秒，平均采样率 24.70 Hz、没有断流，首尾分钟均值仅变化约 0.0124 RPM（0.027%）。
- 相邻进行的 C/D 短测滤波均值分别为 33.7911 和 45.5833 RPM，相对转盘档位标称值高约 1.37% 和 1.30%。转盘实际转速未知，因此这些数值不是 SpinPod 的测量误差，也不能用于判定 ±1% 准确度目标是否达成。
- C/D 实测速度比为 1.34897，档位标称速度比为 1.35，相对仅差约 0.076%。这表明测量线性很好，但约 1.3% 的共同偏移可能来自转盘实际偏快、AirPods 陀螺仪比例偏差或两者共同作用，当前数据无法归因。

因此可以继续开发 iOS 原型，并把“关闭自动人耳检测”和“固定并靠近圆心”作为首次使用的强制引导。当前实验验证了 API 可用性、连续性、精密度、朝向鲁棒性和 10 分钟稳定性。由于目前没有独立转速计，项目以 AirPods 测量结果作为工作值，绝对准确度暂不评价，也不阻塞下一阶段开发。

## 测试环境

| 项目 | 信息 |
|---|---|
| AirPods | AirPods 4 ANC，型号 A3057 |
| AirPods 固件 | 8B39 |
| Mac | MacBook Pro 15-inch, 2019 |
| macOS | 15.7.7（24G720） |
| 自动人耳检测 | 离耳测试时关闭；开启时离耳不上报数据 |
| 放置方式 | 耳机平放、未固定；D/F 靠近中轴，E1/E2 改变朝向与半径 |
| 数据来源 | `.tmp/spinpod-measurement-{A,B,C,D,E1,E2,F}.csv` |

本轮未固定耳机是实验方案的偏差和安全风险。理想刚体的角速度不随半径变化，但半径越大，向心加速度越大，也越容易出现滑动、振动或 Core Motion 传感器融合干扰。后续应固定耳机并尽量靠近中轴。

## 分析方法

- A 对应佩戴基线，B 对应离耳静止，C 对应 33 ⅓ RPM，D 对应靠近中轴的 45 RPM，E1/E2 对应改变朝向与半径后的 45 RPM，F 对应靠近中轴的 45 RPM 十分钟测试。
- 行数不包含 CSV 表头。
- 平均采样率按 `(样本数 - 1) / 记录时长` 计算。
- 转速统计使用 CSV 中 `is_stable=true` 的样本；稳定状态从约 0.76 秒开始。
- “窗口 σ”是 CSV `rpm_stddev` 列在稳定样本中的中位数和最大值。
- 超过 60 ms 的相邻时间间隔计为采样间隙；它表示短时漏样或调度延迟，不等同于耳机断连。
- C–F 的百分比仅表示读数相对转盘档位标称值的偏移，不表示相对真实转速的测量误差。

A 的原始换算值在约 0.016–17.141 RPM 之间随头部动作变化，采样始终保持 25 Hz，足以验证佩戴状态下的数据响应；其记录时长未达到原方案建议的 60 秒，但不影响后续离耳和转速结论。

B 在约 55–62 秒区间出现较多 0.1–0.24 秒短间隙，平均采样率相应下降，但没有长时间停流或断开。C–F 均基本保持约 25 Hz；所有新增测试的最长间隙均低于 0.20 秒，没有超过 0.25 秒的间隙。

## 朝向与放置半径

E2 的三轴角速度分量与 D/E1 明显不同，说明 AirPod 朝向确实发生了较大变化；但程序使用的角速度向量模长仍保持稳定，支持朝向无关的计算方法。

CSV 中的 `userAcceleration` 也清楚显示了半径变化。用 `r ≈ |a|g / |ω|²` 做近似反推，仅用于相对比较，可得到：

| 工况 | 稳态 `|userAcceleration|` 均值 | IMU 推算半径中位数 | 滤波 RPM 均值 | 单次记录标准差 |
|---|---:|---:|---:|---:|
| D 靠近中轴 | 0.0319 g | 约 1.50 cm | 45.58332 | 0.01639 RPM |
| E1 不同半径方案 1 | 0.1857 g | 约 8.66 cm | 45.53559 | 0.01804 RPM |
| E2 不同半径方案 2 并改变朝向 | 0.2844 g | 约 13.41 cm | 45.48758 | 0.01133 RPM |
| F 回到中轴附近 | 0.0448 g | 约 2.04 cm | 45.49303 | 0.01591 RPM |

这些推算半径不是独立测距结果，因为 `userAcceleration` 包含 Core Motion 处理和振动影响；但相对变化与实验操作一致。D、E1、E2 的均值最大相差约 0.0957 RPM（0.210%），可能同时包含转盘随时间变化、半径、滑动与传感器处理差异，不能只归因于某一因素。

结论是：理想陀螺仪角速度本身与半径无关，当前模长算法也能抵抗朝向改变；但靠近圆心能显著降低向心加速度及非理想干扰，还能降低耳机滑出盘面的风险，因此应作为推荐放置方式。

## 十分钟持续性

F 共记录 601.511 秒、14,859 个样本，稳定样本占 99.84%，期间没有超过 0.20 秒的采样间隙。十个整分钟的滤波均值位于 45.4797–45.5016 RPM，范围仅约 0.0219 RPM（0.048%）。第一分钟均值为 45.4832 RPM，最后一分钟为 45.4956 RPM，相差约 +0.0124 RPM（+0.027%）。

F 的全程滤波均值为 45.4930 RPM，单次记录标准差为 0.0159 RPM。数据没有显示随时间恶化、断流或有实际意义的单向漂移，足以通过当前 10 分钟持续性目标。

## 精度边界

本轮转盘没有独立参考转速，33 ⅓ 和 45 RPM 只是档位标称值，不能当作真值。因此本轮不能计算 SpinPod 的绝对误差，也不能判定原定 ±1% 准确度要求是否通过。可计算的只有相对标称偏移和跨档线性：

```text
实测速度比 = 45.58332 / 33.79113 = 1.34897
理论速度比 = 45 / (100/3)       = 1.35000
相对差异                         ≈ -0.076%
```

这支持“传感器能稳定分辨转速，且两档之间近似线性”的结论，但不构成绝对准确度证明。当前阶段直接采用 AirPods 读数：C 代表 33 ⅓ 档的 33.7911 RPM，F 代表 45 档的 45.4930 RPM。如果未来取得可信参考值，再单独评估误差与校准需求。

## 下一步

1. 后续测量固定 AirPod 并尽量靠近圆心，排除滑动并减少向心加速度干扰。
2. 在相同放置方式下对 33 ⅓ 和 45 档各重复至少三次，以 AirPods 读数评估跨次重复性。
3. 在 iOS 原型首次运行时加入“关闭自动人耳检测”的阻断式引导；公开 API 无法代替用户修改该系统设置。
4. 考虑根据 `userAcceleration` 估算放置半径，在半径过大时提醒用户移近圆心；该功能需先验证阈值。
5. 独立参考值不是当前阶段的前提；如果未来能够取得，再单独评估绝对误差，避免把转盘真实偏速错误归因于 AirPods。
